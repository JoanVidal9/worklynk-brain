# Shared operating rules for Codex

This repository is WORKLYNK's shared operational memory. Read `START-HERE.md` first and then only the notes named there for the task at hand. Do not scan the whole vault by default.

When a task changes durable business, product, architecture, deployment, or repository context, update the relevant concise note in this vault and append a handoff entry in `Handoffs.md`. Do not record credentials, client-private data, raw logs, or whole conversation transcripts.

The code repository remains the source of truth for implementation details. The vault records only the context another agent needs before opening that repository.

Do not modify a code repository from this vault task unless the user has explicitly asked for that implementation work.
